# Pilates Studio App

Quick dev start
----------------

Start both backend (Rails API) and frontend (Vite) with one command.

Requirements: have either `overmind` or `foreman` installed for process management. If neither is installed the helper will run both servers in background.

Run:

```bash
./dev
```

This executes `Procfile.dev` (backend on port 3000, frontend on 5173).
